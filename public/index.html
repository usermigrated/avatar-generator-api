Dynamic Avatar Generator API

Generate lightweight SVG avatars from a person's name. Configure initials, colours and image dimensions directly through query parameters—no SDK or client-side library required.

Overview

The API accepts a name and optional styling parameters, then returns an SVG image. Use the generated URL anywhere an image URL is supported, including HTML, React, email templates and profile lists.

SVG outputScalable vector image returned directly by the endpoint.
Automatic initialsExtracts initials from single-word and multi-word names.
Custom coloursSet background and text colours using hexadecimal values.
Flexible dimensionsChoose a square image size between 16 and 512 pixels.

Quick start

Make a GET request by adding a URL-encoded name to the endpoint.

https://ui-avatars.netlify.app/api/?name=Saad%20Masood

Use the URL directly in an image element:

<img
  src="https://ui-avatars.netlify.app/api/?name=Saad%20Masood"
  alt="Saad Masood avatar"
  width="64"
  height="64"
/>
Always URL-encode names that contain spaces, symbols or non-ASCII characters. In JavaScript, use encodeURIComponent().

Query parameters

All parameters are optional. If omitted or invalid, the documented default is used.

The current API automatically calculates text size from the image dimensions. A separate font-size parameter is not currently supported.

Initial generation

Initials are derived from Unicode grapheme clusters, helping the API avoid splitting many combined characters and emoji sequences.

Input nameOutputRule
SaadSAFirst two grapheme clusters of a single word.
DDOne-character name remains one character.
Den MarkDMFirst grapheme of the first and last words.
John Michael SmithJSFirst grapheme of the first and last words.
For a single-word name, up to two grapheme clusters are displayed. For a name with multiple words, the first grapheme of the first and last words is used.

Colours and styling

Hexadecimal colours may be provided with or without the leading #. Three-digit and six-digit values are accepted.

Custom background

?name=John%20Doe&background=0D8ABC

Custom text colour

?name=John%20Doe&color=fff

Set both colours

?name=John%20Doe&background=000000&color=ffffff

Random background

?name=John%20Doe&background=random
A random background colour is generated when the request is processed. A cached response may be reused according to the response cache header.

Integration

HTML

<img
  src="https://ui-avatars.netlify.app/api/?name=John%20Doe&size=96"
  alt="John Doe"
>

JavaScript

const name = "John Doe";

const avatarUrl =
  `https://ui-avatars.netlify.app/api/?name=${encodeURIComponent(name)}&size=96`;

document.querySelector("#avatar").src = avatarUrl;

React

function UserAvatar({ name }) {
  const src =
    `https://ui-avatars.netlify.app/api/?name=${encodeURIComponent(name)}&size=96`;

  return <img src={src} alt={`${name} avatar`} width="96" height="96" />;
}

Fetch the SVG markup

const url = "https://ui-avatars.netlify.app/api/?name=John%20Doe";

const response = await fetch(url);
if (!response.ok) throw new Error("Avatar request failed");

const svgMarkup = await response.text();
console.log(svgMarkup);

Response and caching

Success status200 OK
Content-Typeimage/svg+xml; charset=utf-8
Response bodySVG XML markup
Cache-Controlpublic, max-age=3600
Default dimensions64 × 64 pixels
Supported size range16–512 pixels

On success, the response body is SVG markup and can be used as an image source or read as text. If generation fails, the function returns HTTP 500 with a plain-text error message.

Unicode grapheme segmentation and glyph rendering are different concerns. The API's initials logic handles grapheme clusters, but the browser or SVG renderer must also have a font containing the required glyphs. Font appearance can therefore vary by device and language.

Parameter validation

  • Invalid hexadecimal colours fall back to the default colour.
  • Invalid or missing size values use the default size of 64.
  • Sizes are rounded to an integer and constrained to the range 16–512.
  • uppercase=false disables uppercase conversion; other values keep it enabled.
  • If no name is supplied, the API returns an SVG with an empty text element.
