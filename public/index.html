Dynamic Avatar Generator API

A lightweight REST API that generates PNG avatar images dynamically using a person's name. Customize initials, background colors, text colors, image dimensions and font sizes directly through URL parameters.

Overview

Avatar Generator API converts a name into a PNG image. It extracts characters from the provided name and displays them in the center of a customizable image.

Key features
  • Dynamic avatar generation
  • Single and multiple name support
  • Custom background and text colors
  • Random background color generation
  • Custom image size and font size
  • Uppercase and lowercase support
  • Unicode and international language support
  • PNG image output
  • No frontend JavaScript required to display avatars

API Endpoint

GET

Generate Avatar

https://ui-avatars.netlify.app/

Returns a dynamically generated PNG image. All customization options are passed through query string parameters.

URL Parameters

All parameters are optional. If a parameter is not supplied, the API uses its default configuration.

Parameter Description Default Example
name Name used to generate avatar text Empty John Doe
background Background hexadecimal color or random #dddddd 0D8ABC
color Text hexadecimal color #262626 fff
size Image width and height in pixels 64 128
font-size Text font size in pixels 44% of size 40
uppercase Convert generated text to uppercase true false

Initial Generation

The API automatically determines which characters should appear based on the supplied name.

Name Generated Text Logic
John JO First two characters
J J Single character
john doe JD First character of each name
john doe smith JS First and last name initials
For a single name, the API displays up to two characters. For multiple names, it combines the first character of the first and last words.

Background and Text Colors

Both background and text colors accept hexadecimal color values with or without the # prefix.

Custom background

?name=john+doe&background=0D8ABC

Custom text color

?name=john+doe&color=fff

Custom background and text

?name=john+doe&background=000000&color=ffffff

Random background

?name=john+doe&background=random
When background=random is used, a random hexadecimal color is generated for each request.

Unicode and Language Support

The application uses Unicode grapheme segmentation to extract characters correctly from international names. It can register Noto fonts for different writing systems.

Font files must be placed in the fonts directory. Complex scripts such as Arabic and Bengali may require appropriate text shaping support from the rendering engine.

HTML Integration

You can use the API directly inside any HTML image element. No additional JavaScript is required. 

<img
    src="https://ui-avatars.netlify.app/?name=John Doe&background=0D8ABC&color=fff&size=128"
    alt="User Avatar"
>

Dynamic user avatar

const name = "John Doe";

const avatarUrl =
    `https://ui-avatars.netlify.app/?name=${encodeURIComponent(name)}`;

document.querySelector('#avatar').src = avatarUrl;
<img id="avatar" alt="User Avatar">
